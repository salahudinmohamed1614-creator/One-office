Admin panel

The admin panel is where the ONE OFFICE team manages customer requests, services and the website. It runs on the full PHP + MySQL version, so it is not available in this static demo.

Dashboard

Requests by status, 14-day chart, billed / paid / outstanding fees and the most requested services.

Service requests

Search requests, update the status with a note for the customer, record fees and payments, print, and register walk-in requests.

Website content

Manage service categories, services, FAQ and testimonials – changes appear on the website instantly.

Messages

Read, search and reply to messages sent from the contact page.

Site settings

Texts, contact details, WhatsApp number and switching online requests on or off.

Security

Password hashing, CSRF protection, login lockout after failed attempts and session timeout.
